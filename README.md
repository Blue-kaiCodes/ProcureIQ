# ProcureIQ

A modern enterprise procurement management platform designed to streamline purchase requisitions, supplier management, inventory monitoring, and procurement workflows through a clean, intuitive dashboard.

## Overview

ProcureIQ is a web-based procurement management system focused on providing organizations with a centralized platform for managing purchasing operations.

The platform includes workflow management, supplier tracking, inventory monitoring, approval pipelines, reporting, and administrative tools within a modern enterprise interface.

- 📊 Procurement Dashboard

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Blue-kaiCodes/ProcureIQ.git
```

Move into the project directory:

```bash
cd ProcureIQ
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
